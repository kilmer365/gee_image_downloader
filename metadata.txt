about=PORTUGUÊS: Plugin de Davi Kilmer. Escolha uma camada de polígonos, a imagem (Landsat 4/5/8/9, Sentinel-2 ou MapBiomas) e baixe uma data, a melhor imagem do ano ou uma série multitemporal (por exemplo 1995 até hoje), em composição colorida, cor natural e/ou índices de vegetação (NDVI, GNDVI, NDRE, MSAVI2, NDWI). As imagens são salvas como GeoTIFF em uma pasta e abertas direto no QGIS, sem máscara de nuvens e sem recorte pelo polígono. O MapBiomas já vem com a legenda oficial. DEPENDÊNCIAS EXTERNAS: a biblioteca Python earthengine-api (python -m pip install earthengine-api) e um ID de projeto do Google Earth Engine PRÓPRIO e individual de cada usuário (projeto do Google Cloud registrado no Earth Engine, gratuito para uso não comercial); sem esse ID o plugin não funciona. A interface está em português e inglês. ENGLISH: Plugin by Davi Kilmer. Pick a polygon layer, choose the imagery (Landsat 4/5/8/9, Sentinel-2 or MapBiomas) and download one date, the clearest image of a year or a multi-year time series (for example 1995 to today), as a colour composite, natural colour and/or vegetation indices (NDVI, GNDVI, NDRE, MSAVI2, NDWI). Images are saved as GeoTIFF files in a folder and opened straight in QGIS, without cloud masking and without clipping to the polygon. MapBiomas opens with its official legend. EXTERNAL DEPENDENCIES: the Python library earthengine-api (python -m pip install earthengine-api) and your OWN individual Google Earth Engine project ID (a Google Cloud project registered for Earth Engine, free for non-commercial use); the plugin does not work without it. The interface is available in English and Portuguese.
